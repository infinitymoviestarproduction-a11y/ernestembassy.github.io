📘 SECTION A: OBJECTIVE QUESTIONS
1. What is a computer?

A. A cooking machine
B. An electronic device that processes data
C. A washing machine
D. A radio

Answer: B
Explanation: A computer is an electronic device that accepts data, processes it, and produces meaningful information.

2. Which of the following is an input device?

A. Monitor
B. Printer
C. Keyboard
D. Speaker

Answer: C
Explanation: A keyboard is used to enter data into the computer.

3. The brain of the computer is called:

A. RAM
B. CPU
C. Hard disk
D. Monitor

Explanation: The CPU (Central Processing Unit) controls all operations of the computer.

4. Which of these is an output device?

A. Mouse
B. Keyboard
C. Monitor
D. Scanner

Answer: C
Explanation: A monitor displays information from the computer.

Explanation: Information is processed data that is meaningful.
