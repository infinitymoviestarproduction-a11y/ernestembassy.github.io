Introduction to Digital Technology & Systems

Conceptual Framework

Digital technology refers to electronic tools, systems, devices, and resources that generate, store, or process data using binary code. Binary code consists of two discrete states: 0 (off/low voltage) and 1 (on/high voltage). Every piece of data—whether an image, a video, a text document, or a voice note—is translated into these fundamental units called bits.

Computer Architecture & Functional Units

Conceptual Framework

Computer architecture describes the operational structure and design of a digital computer system. It outlines how the internal components interact to execute instructions. Every standard computer follows the Von Neumann Architecture, which dictates that data and instructions share the same memory space.

The Four Functional Units

Input Unit

Devices that bridge the external environment and the internal system. They translate human-understandable actions into binary signals.
Examples: Keyboards (matrix switches), mice (optical sensors), scanners.

Central Processing Unit (CPU)

The computational core of the system. It contains two vital subdivisions:

  • Arithmetic Logic Unit (ALU): Performs all mathematical calculations (+, -, ×, ÷) and logical comparisons (AND, OR, NOT, greater than, less than).
  • Control Unit (CU): Directs the flow of data through the system. It fetches instructions from memory, decodes them, and signals the appropriate components to execute them.

Memory Unit

Holds data and instructions dynamically or permanently.

  • Primary Memory (RAM): Volatile storage that holds data currently being processed by the CPU. Loses contents when power is turned off.
  • Secondary Storage: Non-volatile media used to save data permanently (e.g., Hard Disk Drives, Solid State Drives).

Output Unit

Devices that translate binary results from the processing unit into human-readable forms.
Examples: Monitors (pixels), printers (ink/toner on paper), speakers.

Conceptual Framework

Hardware represents the physical, tangible parts of a digital system. These components are categorized based on their location relative to the system's main enclosure (the system unit case).

Internal ComponentsPhysical parts housed completely inside the main system unit chassis.Core processing, power distribution, system cooling, primary data caching.CPU, Motherboard, RAM sticks, Internal Power Supply Unit (PSU), Graphics Card.

The System Bus

Internal components communicate with each other using a network of parallel electronic pathways etched onto the motherboard, known collectively as the System Bus. The system bus is split into three specific functional pathways:

Number Systems

Definition

A number system is a mathematical notation for representing numbers using digits or symbols. Digital computers use multiple number systems for different purposes.

Types of Number Systems

1. Binary (Base 2)

Uses two digits: 0 and 1. The native language of computers. Each digit is called a 'bit'.

Example: 1011₂ = (1×8)+(0×4)+(1×2)+(1×1) = 11₁₀

2. Octal (Base 8)

Uses digits 0-7. Often used as a shorthand for binary.

Example: 17₈ = (1×8)+(7×1) = 15₁₀

3. Decimal (Base 10)

Uses digits 0-9. The standard number system used by humans in everyday life.

Example: 255₁₀ = 2×100 + 5×10 + 5×1

4. Hexadecimal (Base 16)

Uses digits 0-9 and letters A-F (where A=10, B=11, C=12, D=13, E=14, F=15). Commonly used in programming and memory addressing.

Example: 1F₁₆ = (1×16)+(15×1) = 31₁₀

Conversion Methods

Decimal to Binary: Successive division by 2, reading remainders from bottom to top.
Example: 45₁₀ = 101101₂

Binary to Decimal: Multiply each bit by its positional value (powers of 2).
Example: 11011₂ = 16+8+0+2+1 = 27₁₀

Hexadecimal to Decimal: Multiply each digit by its positional value (powers of 16).

Computer Networks

Definition

A computer network is a collection of computers and devices connected together via communications devices and transmission media to share data, hardware, and software resources.

Types of Networks by Size

PAN (Personal Area Network)

Covers the smallest geographical area, typically connecting devices around a single person (e.g., phone, laptop, Bluetooth headset). Range: Up to 10 meters.

LAN (Local Area Network)

Connects computers across a single school campus, office building, or home space. Range: Up to a few hundred meters.

MAN (Metropolitan Area Network)

Maps connections across a whole city or metropolitan district region. Range: 5-50 kilometers.

WAN (Wide Area Network)

Links devices across massive distances, spanning countries, continents, or the entire planet (the Internet is the largest WAN). Range: Unlimited.

Network Topologies

  • Bus Topology: All devices connected to a single central backbone cable.
  • Star Topology: Every device connected to a central hub or switch.
  • Ring Topology: Devices connected in a closed loop; data travels in one direction.
  • Mesh Topology: Every node connects directly to every other node.

Network Devices

  • Router: Forwards data packets between different independent networks.
  • Switch: Sends incoming data packets only to the specific destination device.
  • Hub: Broadcasts data out to every connected computer (older technology).
  • Modem: Modulates/demodulates signals for transmission over telephone lines.
  • NIC (Network Interface Card): Provides physical connection to the network.

Client-Server vs Peer-to-Peer

  • Client-Server: Centralized computers manage network services; clients request services.
  • Peer-to-Peer (P2P): All connected computers are equals; no central server.

Data Security and Cybersecurity

Definition

Data security is the practice of protecting data from unauthorized access, corruption, or theft. Cybersecurity is the broader practice of protecting systems, networks, programs, and data from digital attacks.

Common Cyber Threats

  • Computer Virus: Malicious code that replicates and spreads by attaching to clean files
  • Worm: Self-replicating malware that spreads without user action
  • Trojan Horse: Malware disguised as legitimate software
  • Ransomware: Encrypts user files and demands payment for decryption
  • Phishing: Deceptive messages tricking users into giving away sensitive information (passwords, credit card numbers)
  • Spyware: Secretly monitors user activity
  • Adware: Displays unwanted advertisements
  • Man-in-the-Middle Attack: Attacker intercepts communication between two parties
  • Denial of Service (DoS): Overwhelms a system with traffic, making it unavailable

Data Security Measures

  • Encryption: Converts readable data into an unreadable format
  • Firewall: Monitors and filters incoming/outgoing network traffic
  • Anti-virus Software: Scans, detects, and removes malware
  • Strong Passwords: Use a mix of uppercase, lowercase, numbers, and symbols (e.g., Th3$treet#99)
  • Two-Factor Authentication (2FA): Requires two different forms of verification
  • Regular Backups: Create duplicate copies of important data
  • Software Updates: Keep systems patched against known vulnerabilities
  • User Training: Teach users to recognize phishing and other threats

Characteristics of a Strong Password

  • At least 8-12 characters long
  • Contains uppercase letters
  • Contains lowercase letters
  • Contains numbers
  • Contains special symbols (! @ # $ %)
  • Does NOT contain personal information (name, birthdate)
  • Is NOT a common word or sequence (password, 123456)
